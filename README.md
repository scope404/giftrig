# GiftRig

TikTok Live gifts that play your game. GiftRig turns gifts, likes and follows into things that happen in your Minecraft world, with seven minigames, stream overlays and a built-in server. It runs on your own PC.

**Website:** https://giftrig.app

## Download

Get the latest Windows installer from the [Releases page](https://github.com/scope404/giftrig/releases/latest).

- Windows 10 or 11, 64-bit
- The built-in Minecraft server needs Java 21
- Beta software. The installer is not signed yet, so Windows shows an "unknown publisher" notice: choose "More info", then "Run anyway".
